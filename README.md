# Zen Mods

Mods for [Zen Browser](https://zen-browser.app/), installed through [Sine](https://github.com/CosmoCreeper/Sine). Open a mod's README for its installation link and settings.

| Mod | What it does |
| --- | --- |
| [Glance Controls](glance-controls/) | Position, resize, reorder and hide Glance buttons, plus a Copy URL button. |
| [Define Word](define-word/) | Look up selected English and Hebrew words in a dictionary popup. |

Install each mod using its **folder URL**, not this repository's root. The root's catalogue entry is empty and can be removed if installed accidentally.
