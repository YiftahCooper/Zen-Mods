# Local verification

Run `npm test`, `node build.mjs --check` and `node --check define-word.uc.js` from the Define Word directory. `package.json` owns the version: `node build.mjs` writes `src/version.mjs` and stamps it into `src/selection.sys.mjs` and both actor modules (import URL and `DefineWordV<x_y_z>` export names), and `--check` fails if any of them, the bundle, or `theme.json` drifted. Bump `package.json` and `theme.json`, then rebuild. Fixtures cover provider envelopes, credentials, selection ownership, cancellation, settings, popup interactions and geometry. They do not require personal API keys.

`node tests/browser-qualification.mjs` tests production HTML/CSS with real Chromium input, image/layout rendering and synthetic credential storage. A simulated XUL panel provides the platform boundary; it does not establish native Gecko widget geometry or Firefox credential-manager delivery. The qualification used Playwright 1.62.1 and Chromium revision 1234. Resolve Playwright normally, or set `BROWSER_TEST_NODE_MODULES` to an existing node_modules directory; `BROWSER_TEST_EXECUTABLE` selects an existing browser executable outside the default cache.

Its fresh profiles, routine reports and screenshots are regenerable under `.backup-scratch/browser-qualification/`; network access is blocked and only its own context is closed. Do not supply an everyday browser profile. This scope's backup exclusion remains unverified. No global environment, normal browser or backup setting is modified.

Native Gecko fixtures remain in `tests/native/`. Their disposable Zen launch attempts must retain exact-profile guards and owned-process cleanup. Vanilla startup from the current automated tool session fails before Marionette with 0xC0000005; a normal Windows session has run native tests separately, but those receipts do not qualify this release. The main README records the boundary. Do not treat Chromium or source/model test success as native acceptance. Retain unique regression source here; routine probe attempts and copies belong in scratch.

Free Dictionary API requests use a lowercase path because its server normalizes the term that way and its CDN caches URL casing separately. Keep request/display normalization provider-specific. The regression suite covers this route, a stalled request followed by successful retry, and HTTP 522 remaining an availability error. Live probes may still fail during a provider outage and are not part of deterministic `npm test`.
