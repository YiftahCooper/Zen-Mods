## Proportionate optimisations and hardening

- Weakly cached normalized search fields/tokens; no service, database or dependency.
- Large search results use the same cancellable, 30-record frame batches as initial
  rendering. Own picker mutations no longer trigger a full folder/image refresh.
- Provider focus is restored after checkbox rerender; search has a visible focus
  outline. Catalogue refresh reuses the view, not an unrelated new popup.
- Linked custom roots/ancestors refused before creating or scanning directories;
  startup cannot bypass that check. Optional manifests limited to 1 MiB.
- Removed duplicate custom-directory creation and duplicate fallback refresh.
- Live harness now clicks the actual folder result and requires serialized icon
  persistence; it no longer substitutes the native setter for the interaction.
  Visible image geometry and immediate parent opacity are checked too.
- README-SINE.md distinguishes the small mod from the upstream browser checkout.

Node-only search benchmark on the 3,693-record corpus: first query 28.54 ms,
subsequent sampled queries 1.08–5.47 ms, versus approximately 28–43 ms per nonempty
snapshot in the audit. Additional category aliases intentionally broaden some
matches. These are model timings, NOT browser opening/layout measurements.

## Explicit limits and deferrals

- Visual acceptance in actual Zen is still pending the user's test, including
  sidebar/menu shape/colour rendering and native keyboard/focus behaviour.
- Offline runtime tests use real runtime/imports with a small DOM/I/O boundary
  fixture; they are not a Firefox layout engine or cross-realm acceptance test.
- Native folder state across restart/multiple windows and folder-ID remapping
  deserves the later manual acceptance pass. The legacy outline preference map
  is not pruned automatically: absent folders may belong to another window or
  pending restoration, so speculative deletion could lose user choices.
- Raster files still have a compressed-byte limit, not a decoded-pixel bound.
  A format-aware dimension validator remains optional hardening; no new decoder
  dependency or arbitrary user-image sizing restriction was added in this repair.
- Future upstream duplicate concepts remain guarded by catalogue generation
  checks; this is not a guarantee against unknown future Zen catalogue changes.
- Legacy backups stay preserved but are refused by the new automatic rollback.
  An interrupted pre-validation stage is retained for inspection, not guessed at.

These deferrals do not reopen any of the nine confirmed audit findings.
