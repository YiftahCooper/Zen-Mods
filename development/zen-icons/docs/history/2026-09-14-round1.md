## Zen Icons repairs

1. **Tab/space Lucide image paint.** The installed Zen 1.22.1b code was inspected
   directly from `C:/Program Files/Zen Browser/browser/omni.ja`. Native space
   image styles forward fill but not the context-stroke used by the Lucide
   assets. New tab/space selections use generated `display-lucide/` SVGs with
   self-contained light/dark paint. Folder selections retain the original
   recolourable assets. Scoped native-image CSS supplies the missing stroke
   context for already-saved original Lucide sources without migrating state.
2. **Emoji selection delivery.** Selection no longer depends on finding and
   clicking a hidden native picker button. Every result uses the existing
   callback/promise bridge. Tab and folder callers receive UTF-8 SVG image
   values; spaces retain native emoji text.
3. **Default preview.** Tab and space use separate square/circle placeholders,
   not the Lucide space-bar key. Folder Default still uses its native SVG.
4. **Readily available colour icons.** Known folder callers now offer the
   built-in emoji provider despite the native image-only picker option. Emoji
   images retain their colours; they are not classified as monochrome for
   recolouring. System font support still determines which emoji glyphs exist.
